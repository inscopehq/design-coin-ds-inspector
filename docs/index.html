DS Inspector

Click any element in a prototype → see its Coin component, variant, Figma variable names, deviations, and whether it exists in code (Storybook) or design (Figma).

Plug it onto any prototype — no code changes

Drag this button to your bookmarks bar once:

🔎 DS Inspect

Then open any deployed prototype — Vercel, Pages, localhost, anywhere — and click the bookmark. The inspector loads into that page.

If nothing appears, the site sets a Content-Security-Policy that blocks external scripts — use the embed line below instead.
