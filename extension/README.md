# DS Inspector — Chrome extension

1. Download `ds-inspector-extension.zip` from the site (or use this folder).
2. Unzip it. Open `chrome://extensions`, turn on **Developer mode** (top right).
3. **Load unpacked** → pick the unzipped folder.
4. Open any prototype — deployed, localhost, or a local file — and click the
   DS Inspector icon in the toolbar. Click any element.

Updating: download the new zip and Load unpacked again (or `git pull` if you
loaded it from the repo's `extension/` folder — then just press the reload
icon on chrome://extensions).
